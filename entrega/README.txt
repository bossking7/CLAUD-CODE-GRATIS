🚀 COMO VISUALIZAR
──────────────────
1. Abra a pasta "entrega"
2. Dê dois cliques em **index.html**
3. O site abrirá no seu navegador padrão (Chrome, Edge, Firefox)
4. Navegue pelo menu, clique em "Como Funciona" para ver a página extra


🔧 PERSONALIZAÇÃO (quando o cliente tiver conteúdo real)
────────────────────────────────────────────────────────
• **Imagens:** Substitua os arquivos em site_moderno/imgs/ mantendo os mesmos nomes
  - bg-house.jpg → Foto real da casa/jardim (1920x1080 recomendado)
  - g1.jpg → Foto do escritório ou fachada
  - g3.jpg, ext2.jpg → Fotos reais de imóveis/galeria

• **Textos/Preços:** Edite o arquivo index.html e como-funciona.html
  - Preços dos serviços (seção "Nossos Serviços")
  - Horários de atendimento
  - Telefones, e-mail, endereço
  - Depoimentos reais

• **WhatsApp:** O número já está configurado (55 94 98159-8881)


🌐 PARA COLOCAR ONLINE (OPCIONAL)
─────────────────────────────────
Opção 1 - GitHub Pages (GRÁTIS):
  1. Crie repositório no GitHub
  2. Faça upload de TODA a pasta "entrega"
  3. Settings → Pages → Deploy from branch → main
  4. Aguarde 2-3 min → URL: https://usuario.github.io/repositorio/

Opção 2 - Netlify (GRÁTIS, mais fácil):
  1. Acesse netlify.com
  2. Arraste a pasta "entrega" para a área de deploy
  3. Pronto! URL gerada na hora

Opção 3 - Hospedagem própria:
  - Envie via FTP para public_html ou www


⚠️ IMPORTANTE
─────────────
• Mantenha a estrutura de pastas (index.html na raiz, imgs em site_moderno/imgs/)
• Não renomeie index.html (é o arquivo principal)
• As fontes (Google Fonts) e ícones carregam via CDN - precisa de internet
• O site é responsivo (funciona no celular, tablet, desktop)
